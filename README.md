## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or serve it locally using any static web server:

### Option 1: Double-click or open directly
Double-click `index.html` in File Explorer or open it in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Using Node / npx
```bash
npx serve .
```

### Option 3: Using Python
```bash
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
